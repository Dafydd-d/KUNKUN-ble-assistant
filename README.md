# 坤坤蓝牙助手

Windows 桌面端 BLE 无线串口调试工具（V1.1）。数据链路：**电脑（本程序）↔ BLE 透传模块 ↔ MCU**，程序通过 BLE 写入/通知特征与透传模块收发数据，模块另一侧是串口 UART。

- 界面：PySide6 (Qt)，Fusion 风格，双主题、中英双语
- 通信：bleak 3.x（Windows 走 WinRT），asyncio 事件循环运行在独立线程
- 入口：`ble_serial_assistant.py`；BLE 引擎 `ble_engine.py` 与界面解耦，可脱离 Qt 复用

## 运行

**源码运行**（Python 3.10+）：

```bash
pip install -r requirements.txt
python ble_serial_assistant.py
```

或双击 `启动.bat`（优先使用 `%LOCALAPPDATA%\PyBuild\Python312\python.exe`，否则回退 PATH 中的 `python`）。

**打包为 exe**：

```bash
pyinstaller BLE串口助手.spec
```

产物 `dist/坤坤蓝牙助手.exe`：单文件、无控制台、带图标（`app_icon.ico`），运行期把 `ble_serial_config.json` 与 `logs/` 生成在 exe 同目录。

## 功能（按代码实现）

### 扫描与设备列表
- 程序启动 300 ms 后即开始**持续扫描**（无扫描按钮）；扫描意外停止后 3 秒自动重启
- 每个设备一张卡片：蓝牙图标、名称、MAC 地址、4 格信号条 + RSSI 数值
- RSSI 分格阈值：≥ −55 满格 4 格、≥ −67 三格、≥ −80 两格、其余一格；**±127 视为「无测量值」占位符**，只保留最近一次真实测量
- 「名称过滤」框按名称或地址（不区分大小写）即时过滤
- 停止广播超过 **10 秒**的设备自动从列表移除（正在连接/已连接的设备保留）
- 单击卡片选中，**双击卡片或点【连接】按钮**发起连接

### 连接与服务识别
- 连接超时 15 秒；仅空闲状态可发起连接
- 连接成功后自动列出全部 GATT 服务与特征（树形：UUID + 属性），已知 UUID 显示友好名称（NUS、HC-04/HM-10、ISSC、Generic Access 等）
- 透传特征自动识别，按以下顺序：
  1. **Nordic UART (NUS)**：`6e400002…` 写入 + `6e400003…` 通知
  2. **HC-04 / HM-10 / AT-09**：`0000ffe1…` 单特征同时具备 write + notify
  3. **ISSC/Microchip**：`49535343-8841…` 写入 + `49535343-1e4d…` 通知
  4. 回退一级：同一服务内「可写特征 + 可通知特征」成对（通知端优先选只 notify 的纯通知特征）；跳过系统服务（1800/1801/180A/180F/1812/1813）
  5. 回退二级：单个特征同时可写 + 可通知（自定义 UUID 模块常见形态）
  6. 回退三级：任意可写特征 + 任意可通知特征
- 通知订阅失败不中断连接，可在特征区重新应用重试订阅

### 特征选择与记忆
- 「写入 / 通知」两个下拉框可手动指定特征；**下拉变更即自动生效**（300 ms 防抖，已连接时），也可点【应用特征设置】立即生效
- 手动指定**按设备（MAC）记忆**，写入配置文件；重连时若记忆的特征仍在列表中则优先于自动识别结果，并自动重订通知
- 切换特征时先对旧通知特征取消订阅，再订阅新的

### 接收监视（深色仪表屏）
- 显示模式三选一：**ASCII / HEX / 混合**（HEX + ASCII 对照，ASCII 侧的 `\r` `\n` 转义显示）；切换只影响之后新到的数据
- 每行带毫秒级时间戳（`HH:MM:SS.mmm`，取通知到达瞬间）
- 三个开关：**自动滚动**（默认开）、**回显发送**（默认开，TX 青色显示）、**自动日志**（默认关）
- 行着色：RX / TX / 信息 / 警告 / 错误 五色
- 显示区最多保留 4000 行，超出裁到 3000 行（完整内容仍在内存与日志中）
- 底部实时读数：RX 字节/包数、TX 字节；【保存日志…】导出 TXT，【清空】清屏并重置统计

### 发送
- 格式 **ASCII**（utf-8 / gbk 编码，无法编码的字符替换）或 **HEX**（空格可省略，必须为偶数个十六进制字符，否则弹错）
- 行尾可选：无 / `\r` / `\n` / `\r\n`
- **定时发送**：周期为 ≥ 50 的整数毫秒，重复发送输入框当前内容；运行期间内容/格式可随时修改（每 50 ms 快照到引擎）；再点按钮停止，断开连接也会停止
- **8 个预设命令槽**：点【发】按当前格式/编码/行尾立即发送，内容持久化
- 发送优先使用 **write-without-response**，特征不支持时退回有应答写

### 连接保活与掉线检测
- **连接看门狗**：每 2 秒读一次特征做心跳（优先透传特征本身，否则任意可读特征；无只读特征的设备只能依赖系统断开回调），3 秒超时，连续 2 次失败判定远端掉线并主动断开
- 远端断电/超出范围时：系统断开回调或看门狗触发，自动清理特征区、停止定时发送、状态灯回灰
- 主动断开（【断开】按钮）与被动掉线在日志中区分显示

### 状态栏
- 顶部链路状态灯：灰=空闲、橙=连接中、绿=已连接；旁边显示当前目标设备（连接中/已连接时显示**实际连接的设备**，空闲时显示列表选中设备），设备名与 MAC 可拖选、双击复制、右键菜单
- 底部读数：MTU、接收（字节/包）、发送（字节）

### 日志
- **自动日志**：开启后所有收发与提示行实时写入 `logs/ble_YYYYMMDD.log`，按天自动分文件，每秒刷盘，会话开始/结束打标记
- **手动保存**：导出 UTF-8 TXT，含时间戳会话头 + 接收区全部行

### 界面与偏好
- 双主题：**浅色「仪器工作台」/ 深色「电台面板」**，菜单【工具】热切换（不丢收发数据与设备列表），Win10/11 深色标题栏跟随主题（DWM API）
- 中文 / English 双语：菜单【工具 → 语言】切换，界面与引擎运行日志同步翻译
- 配置记忆 `ble_serial_config.json`（自动生成，exe/脚本同目录），退出时保存：主题、语言、每设备特征偏好、收发格式/编码/行尾、显示模式、开关状态、定时周期、发送内容、8 条预设、窗口几何与最大化状态、自动日志开关

## 项目结构

```
ble_serial_assistant.py   界面主程序 (PySide6, 约 1800 行)
ble_engine.py             BLE 引擎: 扫描/连接/识别/收发/看门狗/定时发送
                          (asyncio 跑在独立线程, 事件队列回调与 UI 通信)
i18n.py                   双语词条 (以中文为键, ctx 区分同文异义)
tests/                    5 个无头界面回归测试 (offscreen, 无需蓝牙)
启动.bat                   源码启动脚本
BLE串口助手.spec            PyInstaller 配置 (onefile / windowed / icon)
requirements.txt          bleak>=3.0, PySide6-Essentials>=6.6
app_icon.ico / app_icon.png  应用图标资源
```

引擎通过 `sink` 回调抛出的事件类型（供二次开发参考）：
`device_found` / `services` / `uart_ready` / `rx` / `tx` / `log` / `error` / `conn_state` / `scan_state` / `periodic_started` / `periodic_stopped`。
